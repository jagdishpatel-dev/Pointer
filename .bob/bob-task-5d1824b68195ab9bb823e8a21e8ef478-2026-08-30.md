**What was wrong:**

`TinyDB.storage` is typed as the abstract `Storage` base class from tinydb, which only declares abstract methods like `read()` and `write()` — it has no `flush()` method. The `flush()` method is specific to [`CachingMiddleware`](apps/integration/src/integration/storage.py), which buffers writes and exposes `flush()` to commit them to disk.

Because `_db()` always constructs the database with `storage=CachingMiddleware(JSONStorage)`, calling `.flush()` is always valid at runtime — but basedpyright only sees the declared type `Storage` and correctly flags `flush` as unknown.

The fix adds `assert isinstance(db.storage, CachingMiddleware)` immediately before each `.flush()` call. This serves two purposes:
1. It narrows the type from `Storage` → `CachingMiddleware`, satisfying the type checker.
2. It acts as a runtime guard that will raise `AssertionError` if the storage is ever changed to something other than `CachingMiddleware`, preventing a silent failure.
