**Root cause**

PyGithub's `get_pulls()` returns a `PaginatedList[PullRequest]`, but due to its generic implementation, basedpyright infers the loop variable `gh_pr` as the raw `GithubObject*` base type rather than `PullRequest`. That means:

1. `gh_pr.number` — `number` is defined on `PullRequest`, not the opaque `GithubObject*` base, so the attribute lookup fails.
2. `ingest_pr(gh_pr.number, ...)` — because `number` was unknown, its type was also unknown, causing the second error.

**Fix**

Added `from typing import cast` and wrapped the access as `cast(GHPullRequest, gh_pr).number`. This tells the type-checker to treat `gh_pr` as a `GHPullRequest` (which it is at runtime), making `number` a known `int` and fully satisfying the `pr_number: int` parameter of [`ingest_pr()`](apps/integration/src/integration/ingestion/_legacy.py:113).
