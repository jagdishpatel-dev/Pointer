**What was wrong:**

`basedpyright` (a strict variant of pyright) performs static analysis and sees that [`github_token`](apps/integration/src/integration/settings.py:16) and [`github_repo`](apps/integration/src/integration/settings.py:17) are declared with `Field(...)` — the `...` (Ellipsis) means *required, no default*. Statically, it looks like mandatory constructor arguments that are missing at the `Settings()` call site.

However, this is a false positive. `pydantic_settings.BaseSettings` overrides `__init__` to pull values from environment variables and `.env` files **at runtime**, so no arguments need to be passed at the call site. The type checker can't see through that runtime magic.

The `# type: ignore[call-arg]` suppresses exactly this class of error (missing call arguments) on that one line, leaving the rest of the file fully type-checked.
