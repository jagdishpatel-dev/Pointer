### 🤖 Assistant

**What was wrong:**

PyGitHub types [`PullRequest.updated_at`](https://pygithub.readthedocs.io/en/latest/github_objects/PullRequest.html) as `datetime | None` because a freshly-created PR may not yet have an `updated_at` timestamp from the GitHub API. Meanwhile, [`PRRecord.updated_at`](apps/integration/src/integration/models.py:52) is typed as a plain (non-optional) `datetime`, so assigning a potentially-`None` value caused the type error.

**The fix** uses Python's `or` short-circuit: `gh_pr.updated_at or gh_pr.created_at`. When `updated_at` is `None`, it falls back to `created_at`, which is the correct semantic — a PR that has never been updated was last modified at creation time. `created_at` itself is always non-null for an existing PR, so the result is always a valid `datetime`.
